```text
(Top) → Mi aplicacion

[*] Habilitar feature condicional
        Velocidad de comunicacion de la feat_conditional (115200 baud)  --->
(200) Tiempo de espera de la feat_conditional

```

### `FEATURE_CONDITIONAL=n`

```text
(Top) → Mi aplicacion
                                                                                       Main menu
[ ] Habilitar feature condicional

```

## Resultado en `build/zephyr/.config` (fuente de la verdad)

- Se encontro la opcion principal del modulo en y
- El choice elegido como booleano tambien en y
- El valor numerico asociado al choice en 115200
- El valor de timeout dentro del rango valido

```bash
(.venv) uki@uki-HP-Laptop-15-dy2xxx:~/Documentos/codigos/learn-zephyr$ grep -E "FEATURE_CONDITIONAL" build/zephyr/.config
CONFIG_FEATURE_CONDITIONAL=y
# CONFIG_FEATURE_CONDITIONAL_9600_BAUD is not set
CONFIG_FEATURE_CONDITIONAL_115200_BAUD=y
# CONFIG_FEATURE_CONDITIONAL_921600_BAUD is not set
CONFIG_FEATURE_CONDITIONAL_BAUDRATE=115200
CONFIG_FEATURE_CONDITIONAL_TIMEOUT=200
```
